# AADUKALAM FITNESS CLUB

An engaging, responsive website for AADUKALAM FITNESS CLUB, built to help visitors explore training programs, compare membership plans, and take the first step toward their fitness goals.

**Live website:** [ahamed0090k-commits.github.io/FITNESS-CLUB](https://ahamed0090k-commits.github.io/FITNESS-CLUB/)

## Features

- Fitness club landing page with club information and training programs
- Individual detail pages for seven fitness programs
- Three membership plans with a plan-specific registration form
- Responsive layouts for desktop and mobile screens
- Client-side navigation with GitHub Pages route fallback

> Registration is currently a front-end demo. Submitted details are not sent to a server or saved.

## Built With

- React
- React Router
- Vite
- Bootstrap
- Lucide React

## Run Locally

Install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Vite prints the local URL in the terminal.

## Production Build

Create and preview a production build:

```bash
npm run build
npm run preview
```

## Deployment

Pushing to `main` automatically builds and deploys the site to GitHub Pages using the workflow in `.github/workflows/deploy.yml`.
